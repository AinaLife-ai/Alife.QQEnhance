# Alife.QQEnhance

QQ增强插件：贴表情、点赞、撤回、禁言、戳一戳、引用回复、合并转发、音乐卡片、感知通知、输入中状态、戳回决策

从 KiraAI 的 [kira-ai-plugin-qq-enhance](https://github.com/xxynet/kira-ai-plugin-qq-enhance) 移植到 Alife 框架。

## 功能

- 给QQ消息贴表情
- 给QQ用户资料卡点赞
- 撤回QQ消息
- 禁言QQ群成员
- 群聊戳一戳成员
- 私聊戳一戳用户（`friend_poke`）
- **戳回决策**：收到别人的戳一戳后，注入决策提示让模型顺带决定是否回戳（`PokeBack`），不影响正常回复构建，30秒冷却防刷屏
- 引用回复消息（结构化 reply 参数，失败自动回退 CQ 码）
- **ReplyRecent**：引用回复指定用户的最近一条消息，无需消息ID（插件自动从实时缓存定位）
- 合并转发（转发已有合并转发 / 构造新合并转发）
- **ForwardRecent**：转发某群最近N条消息为合并转发，无需构造JSON/传ID
- 发送QQ音乐卡片
- 感知自己被禁言/解除禁言（通知携带群号与群名）
- 感知新成员进群（通知携带群号与群名）
- 获取群聊/私聊最近消息及消息ID（`QGetMessages`，用于定位撤回/贴表情/引用回复/转发目标）
- 私聊输入中状态

## 与 YuYang.QQTools（幼央工具箱）兼容

本插件可检测幼央工具箱是否已加载且被当前角色启用，自动分工避免功能重复：

| 兼容模式 | 行为 |
|---|---|
| `Auto`（默认） | 检测到幼央 → 重叠功能（戳一戳/引用回复/点赞/贴表情/撤回/输入中）自动让位，AI 调用时提示改用幼央函数；幼央卸载后自动恢复 |
| `PreferQQEnhance` | 无视幼央，全部功能由本插件提供 |
| `PreferYuYang` | 重叠功能一律让位（幼央未装时自动回退自持） |
| `Off` | 不检测，全功能注册，手动管理 |

本插件独有（幼央没有）：禁言、音乐卡片、合并转发、QGetMessages 实时ID、感知通知、ForwardRecent、ReplyRecent、PokeBack。

## 依赖

- `Alife.Function.FunctionCaller`（Xml函数执行器）
- `Alife.Function.QChat`（QQ聊天模块）

## 安装

将 `Alife.QQEnhance` 文件夹放入 Alife 的 `Plugins` 目录，同步环境后启用模块即可。

## 配置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 贴表情 | 启用给QQ消息贴表情功能 | 开启 |
| 点赞 | 启用给QQ用户资料卡点赞功能 | 关闭 |
| 撤回 | 启用撤回QQ消息功能 | 开启 |
| 禁言 | 启用禁言QQ群成员功能 | 开启 |
| 戳一戳 | 启用群聊戳一戳成员功能 | 开启 |
| 戳回决策 | 收到戳一戳后注入决策提示（PokeBack），不影响正常回复 | 开启 |
| 引用回复 | 启用引用回复消息功能 | 开启 |
| 合并转发 | 启用合并转发消息功能（转发已有/构造新转发/转发最近消息） | 开启 |
| 音乐卡片 | 启用发送音乐卡片功能 | 关闭 |
| 兼容模式 | 与幼央工具箱的协作模式（Auto/PreferQQEnhance/PreferYuYang/Off） | Auto |
| 感知群禁言 | 感知自己被禁言/解除禁言并通知AI | 开启 |
| 感知成员进群 | 感知新成员进群并通知AI | 开启 |
| 输入中状态 | 私聊时发送输入中状态 | 开启 |
| 输入中延迟(秒) | 收到消息后延迟多久开始发送输入中状态 | 2.0 |
| 输入中间隔(秒) | 输入中状态刷新间隔 | 2.0 |
| 输入中最大时长(秒) | 输入中状态最大持续时长 | 60.0 |
| 实时消息捕获 | 独立WS监听实时事件捕获真实消息ID | 开启 |
| 实时消息缓存大小 | 缓存最近N条实时消息的消息ID/内容 | 200 |

## 注意事项

- 需要先启用 Alife 官方 QQ聊天模块（`Alife.Function.QChat`）
- 本插件通过反射访问 `QChatService` 内部的 `OneBotClient`，不修改官方代码
- **QQ平台消息ID为负数**。撤回/贴表情/引用回复/转发必须使用 `QGetMessages` 返回的真实消息ID，严禁编造或猜测（否则 RetCode 100/1400）
- 想省事时可以直接用 `ForwardRecent`（转发最近N条）/`ReplyRecent`（回复某人最近一条），不用查ID，插件自动从实时捕获缓存定位
- 引用回复使用 OneBot 结构化 `reply` 参数（`send_msg` 的 `reply` 字段），失败时自动回退 `[CQ:reply]` CQ 码方式
- 私聊戳一戳使用 `friend_poke`（NapCat/LLOneBot 支持），群聊戳一戳使用 `group_poke`
- 合并转发构造节点：`{"name":"昵称","uin":QQ号,"content":"内容"}` 自定义内容，或 `{"id":真实消息ID}` 引用真实消息；`id` 支持数字与数字字符串；JSON 缺收尾括号时自动补全；解析失败给出含正确示例的提示
- 实时消息捕获参考了 [YuYang.QQTools](https://github.com/3026838203/YuYang.QQTools) 的 WebSocket 监听思路，特此致谢
